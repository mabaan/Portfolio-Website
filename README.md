<h1>Portfolio Website</h1>

<p>A personal portfolio website built with <a href="https://astro.build">Astro</a>, React, and Three.js. Styled with Tailwind CSS and deployed on Vercel.</p>

<hr>

<h2>Tech Stack</h2>

<ul>
  <li><strong>Framework:</strong> Astro 5</li>
  <li><strong>UI Components:</strong> React 19</li>
  <li><strong>3D Graphics:</strong> Three.js · React Three Fiber · Drei</li>
  <li><strong>Styling:</strong> Tailwind CSS</li>
  <li><strong>Deployment:</strong> Vercel</li>
</ul>

<h2>Pages</h2>

<ul>
  <li><code>/</code> — Home / Hero</li>
  <li><code>/about</code> — About</li>
  <li><code>/experience</code> — Experience Timeline</li>
  <li><code>/projects</code> — Featured Projects</li>
  <li><code>/contact</code> — Contact Form</li>
</ul>

<h2>Getting Started</h2>

<pre><code># Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
</code></pre>

<h2>Project Structure</h2>

<pre><code>src/
├── components/   # React components
├── layouts/      # Astro layouts
├── pages/        # Routes & API endpoints
├── styles/       # Global CSS
└── utils/        # Utility functions
public/           # Static assets
</code></pre>
